# 重要性

第十三章的旅行助手项目中，我们体验了如何将 HelloAgents 应用于一个多智能体产品。本章我们继续向前，聚焦「知识密集型应用」：构建一个能够自动化执行深度研究任务的智能体助手。

相比旅行规划，深度研究的难点在于信息的不断发散、事实的快速更新以及用户对引用来源的高要求。为了交付可信的研究报告，我们需要让智能体具备三个核心能力：

（1）问题剖析：将用户的开放主题拆解为可检索的查询语句。

（2）多轮信息采集：结合不同搜索 API 持续挖掘资料，并去重整合。

（3）反思与总结：依据阶段结果识别知识空白，决定是否继续检索，并生成结构化总结。

14.1 项目概述与架构设计
14.1.1 为什么需要深度研究助手
在信息爆炸的时代，我们每天都需要快速了解新的技术、概念或事件。传统的研究方式有几个痛点。首先是信息过载。搜索引擎返回成千上万的结果，你需要逐个点开链接，阅读大量内容，才能找到有用的信息。其次是缺少结构。即使找到了相关信息，这些信息往往是碎片化的，缺少系统性的组织。最后是重复劳动。每次研究新主题时，都需要重复"搜索→阅读→总结→整理"的过程。

这就是深度研究助手需要解决的问题。它不仅仅是一个搜索工具，而是一个能够自主规划、执行和总结的研究助手。

深度研究助手的核心价值：

节省时间：将 1-2 小时的研究工作压缩到 5-10 分钟
提高质量：系统化的研究流程，避免遗漏重要信息
可追溯：记录所有搜索结果和来源，方便验证和引用
可扩展：可以轻松添加新的搜索引擎、数据源和分析工具

## 1. 核心运行逻辑速查表（帮你搞懂它是怎么干活的）
传统的 AI 查资料只会单次联网搜一下，而深度研究智能体采用的是 “TODO（任务）驱动的研究范式”。它的工作流程就像一个专业的商业分析师：

| 阶段名称 | 扮演的角色 | 它的通俗大白话逻辑 | 实践中它输出了什么？ |
|---|---|---|---|
| 阶段 1：规划 (Planning) | 定大纲的行业专家 | 看到你的研究主题后，大模型不急着搜索，而是先用脑子把主题拆解成 3-5 个具体的子任务（TODO 列表）。 | 生成一个包含【子任务标题、研究意图、精准搜索关键词】的 JSON 任务列表。 |
| 阶段 2：执行 (Execution) | 跑腿的资料搜集员 | 顺着大纲列表，挨个去不同的搜索引擎（如 Tavily、DuckDuckGo）检索资料，把一堆网页倒进脑子里，去重、精简并提炼出干货笔记。 | 为每个子任务生成一份【带网页来源链接、数据详实】的 Markdown 干货总结。 |
| 阶段 3：报告 (Reporting) | 总成稿的首席主笔 | 把所有子任务的干货笔记全部收上来，合并重复信息，加上大背景概述和最终结论，揉成一篇精美完整的长文大报告。 | 交付一份结构完整、带正规参考文献列表的 Markdown 深度研究报告。 |

## 2. 深度研究“三剑客”Agent 天团（在低代码或代码里怎么设计角色）
如果你要在 Dify、Coze 扣子等低代码平台上，或者自己写代码创建这个系统，你需要搭建以下 3 个 Agent 角色的配合：

| 角色名称（Agent 节点） | 核心组件/工具 | 关键指令要点 | 落地实战小撇步 |
|---|---|---|---|
| 1. 研究规划专家 (TODO Planner) | LLM (定大纲) | 将研究主题拆解为 3-5 个逻辑子任务，输出含 title/intent/query 的规范化任务列表。 | 让规划专家在生成关键词时优先使用英文，以获取更精准的国际前沿资料。 |
| 2. 任务总结专家 (Task Summarizer) | LLM + 联网搜索 (Tavily/Perplexity) | 阅读搜索结果并提炼干货，每一句观点必须标注对应的内容来源链接。 | 在节点中设定信息检索长度限制，并在喂给 LLM 前进行文本去重，防止低质量噪音。 |
| 3. 报告撰写专家 (Report Writer) | LLM (整合) | 将所有子任务总结信息“拼装”为【背景 ➡️ 深度分析 ➡️ 总结 ➡️ 参考文献】的完整文章。 | 该节点不启用任何工具，仅专注于信息梳理，确保内容精准不发散。 |

| 功能点 | 技术实现核心 | 场景功能说明 | 低代码平台(Coze/Dify)平替 |
|---|---|---|---|

| 研究结果持久化 | 笔记/文档存储 | 缓存成果，方便随时回溯查询原始记录。 | 在结尾添加“存入数据表格/知识库”的动作。 |

## 🛠️ 3步实战：从零搭建你的深度研究智能体 (以Coze/Dify为例)

   1. 第一步：创建工作流（Workflow）：定义输入为【研究主题】。
   2. 第二步：连线配置：
   * 节点 A (规划)：输入主题，生成 3 个子任务关键词。
      * 节点 B (循环搜索)：使用循环插件对上述关键词逐个进行联网搜索并提炼干货短笔记。
      * 节点 C (综合撰写)：将前一步的短笔记汇总，输出 Markdown 长文报告。
   3. 第三步：防幻觉调优：在节点 B 的提示词中加入强约束：“未搜索到的数据严禁编造，必须如实反映真实搜索情况”。
